# WFS-556 — Garage : badge « NOUVEAU » sur les coloris, finitions et skins gagnés au cadeau du jour
Épic : E19 (code dans la zone E5 : `src/ui/garage_couleur.*`, `garage_finition.*`, `garage_skin.*`, `assets/textes/fr.txt`, `en.txt`) · Priorité : P1 Urgent ·
Dépend de : **WFS-503** (données `cadeau-nouveaux`, `estNouveau` / `vu`) ; **WFS-551** (tient les trois fichiers de panneau) · Agent : `@dev`
Épic et règles communes : `regles-de-gestion/E19-cadeau-du-jour.md`. Né de l'arbitrage PO du 2026-11-15 23:17 UTC sur WFS-503 (RG-02).

## Besoin
Le joueur voit au garage ce que le cadeau du jour lui a donné : un petit texte « NOUVEAU » sur l'objet gagné, qui disparaît quand il le choisit.

## Règles de gestion
- RG-01 **Badge** : texte « NOUVEAU » (FR) / « NEW » (EN), clé `garage.nouveau` dans `assets/textes/fr.txt` et `en.txt`, sur la vignette de l'objet pour lequel
  `estNouveau(s, voiture, objet)` (WFS-503) est vrai, dans les 3 rangées : coloris, finitions, skins. Interface 2D : style de `design-street-racing` et du modèle R19
  (pastilles et couleurs de WFS-551, rien de recréé), lisible sans cacher la vignette ni le cadenas.
- RG-02 **Vu** : quand le joueur choisit l'objet, appel de `vu(s, voiture, objet)` (WFS-503) ; le badge disparaît tout de suite et reste parti après relance.
- RG-03 Seulement la voiture concernée : un coloris gagné pour la voiture A n'a pas de badge sur la voiture B.
- RG-04 Ne rien changer d'autre dans les panneaux (taille des boutons : ordre permanent du 2026-11-06).

## À réutiliser
`estNouveau` / `vu` de WFS-503, panneaux `garage_couleur.*`, `garage_finition.*`, `garage_skin.*` (après WFS-551), `ui::tr` (WFS-504).

## Critères d'acceptation
- [ ] Test CPU ou de banc : badge présent après gain, absent après choix et après relance.
- [ ] Parcours complet : menu → cadeau (coloris) → garage (badge visible) → choix → course → retour garage (plus de badge) → relance, noté au journal.

## Captures demandées (au moins 3, FR et EN, une taille d'écran)
1) garage, rangée des coloris avec le badge sur le coloris gagné ; 2) même rangée après le choix (badge parti) ; 3) rangée des skins avec une skin gagnée « NEW » (EN).

## Hors périmètre
Données et tirage (WFS-503), écran du cadeau (WFS-501), voiture prêtée (WFS-502).
