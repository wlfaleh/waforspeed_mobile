# WFS-553 — [TECHNIQUE] Banc `score-fin` : l'appui sur le compteur d'étoiles ouvre le Market (après WFS-513)
Épic : E22 (banc de WFS-537) · Priorité : P2 Haute · Dépend de : — (WFS-513 et WFS-537 sont ✅) · Agent : `@dev` · Anomalie : ANO-274

## Besoin (qui, quoi, pourquoi)
Signalé le 2026-11-15 par Claude, agent dev3d (01Us6uCucP), pendant WFS-548 (PR #422) : le banc `WFS_BANC=score-fin`
(`src/game/score_fin_banc.cpp`, WFS-537) donne **40 échecs identiques sur `main` et sur la branche**, code de sortie 3.
Premier échec : « SCORE FIN (fr) : appui sur le compteur → garage (RG-09) : ÉCHEC ». Ensuite le banc reste sur un autre écran
et tous les contrôles suivants échouent (course à 5 finie, Poursuite finie, détail du score, « +N ★ », « Rejouer » / « Menu », FR puis EN) ;
les captures `score-fin-*-course5`, `-poursuite`, `-duel` ne montrent pas l'écran de fin.

Cause vue par le PO (à confirmer par le développeur) : **le jeu fait ce qui était prévu**. WFS-537 RG-09 disait : « ouvre le garage
tant que l'écran Market n'existe pas ; WFS-513 le fera ouvrir le Market ». WFS-513 est fusionné : `src/ui/ecrans/menu.cpp` l. 107
ouvre maintenant `market_ecran::ouvrir(Ecran::Menu)`. Le banc attend encore `Ecran::Garage` (l. 143-146) et ne referme pas le Market.
C'est le **banc** qui est en retard, pas le jeu.

## Règles de gestion
- RG-01 Le contrôle 7 du banc devient : appui sur le compteur du menu → **écran Market ouvert** (`market_ecran::ouvert()`), en FR et en EN.
- RG-02 Le banc **referme le Market** (`market_ecran::fermer()` ou le bouton de retour réel) et vérifie le retour au menu avant les étapes suivantes ;
  aucun état du Market ne reste ouvert pour la course à 5, la Poursuite et le duel.
- RG-03 Les autres contrôles du banc ne changent pas (aucun seuil affaibli, aucun contrôle retiré) ; le banc rend **0 échec, code 0**.
- RG-04 On ne touche pas au comportement du jeu (menu, compteur, Market) : seul `src/game/score_fin_banc.cpp` change
  (plus un commentaire à jour dans `score_fin.h` si besoin). Si le développeur trouve que le jeu lui-même est fautif, il le dit au PO avant de coder.
- RG-05 Vérifier si `score-fin` tourne dans un groupe de `matin.yml` / `build.yml` (`tools/qa/banc_groupe.sh`) ; le noter dans la PR.

## À réutiliser
`src/game/score_fin_banc.cpp` (fonctions `toucher`, `images`, `verifier`, `capture`), `src/ui/ecrans/market_ecran.h` (`ouvert()`, `fermer()`),
`src/ui/ecrans/compteur_etoiles.h` (`centre()`), le banc du Market `src/game/market_banc.cpp` comme modèle.

- Captures `score-fin-*-course5`, `-poursuite`, `-duel` : on voit l'écran de fin avec le bloc « Score » et « +N ★ ».

1) menu → appui sur le compteur → écran Market ouvert ; 2) fin de course à 5 avec le détail du score ; 3) fin de Poursuite ; 4) duel ; FR et EN.
