# WFS-357 — Paquets de cartes : boucle sans pause si la fenêtre est perdue (suite WFS-355)

**Épic** : E8 · **Priorité** : P3 Basse (tâche facile, non bloquante) · **Origine** : remarque du lead dev sur la PR #309 (WFS-355).

## Besoin
Après « Plus tard » ou « Continuer » sur l'écran des paquets (état Fini), si la fenêtre Android est perdue avant l'image suivante (appli mise en arrière-plan), la boucle d'`android_main` tourne sans attente (`ALooper_pollOnce(0)`) jusqu'au retour de la fenêtre : batterie consommée pour rien.

## Règles de gestion
- **RG-01** : la condition « sans attente » de l'état Fini des paquets n'est vraie que si la fenêtre existe (`&& a->window`, `src/platform/android_main.cpp` ≈ ligne 364).
- **RG-02** : rien d'autre ne change : CGU, « Accepter », « Plus tard », « Continuer » marchent comme après WFS-355.

## Critères d'acceptation
- Test CPU sur `cgu_appui::boucleSansAttente` (ou équivalent) : état Fini sans fenêtre → attente ; avec fenêtre → sans attente.
- Construction et tests CPU verts ; captures du banc `cgu` inchangées (≥ 3 avant / après, `tools/qa/captures_pr.sh`).
