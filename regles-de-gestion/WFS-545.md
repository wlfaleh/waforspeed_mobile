## Défaut vu (vidéo de l'utilisateur, 2026-11-14 11:39 heure du téléphone, 17 s, écran « Crée ton pilote »)
- Un seul appui écrit plusieurs fois le même caractère : « Rrrrrr », « Ghjjjjj » ; les appuis sur « effacer » partent aussi en série (le champ se vide d'un coup).
- Cause probable trouvée par le PO dans le code (à confirmer par le développeur) : `src/platform/android_main.cpp` envoie au jeu **chaque mouvement du doigt** (`AMOTION_EVENT_ACTION_MOVE`) avec `down = true` ; `toucher()` de `src/ui/ecrans/creation_profil.cpp` (ligne ≈ 90) traite **tout** `down = true` comme un nouvel appui → un doigt posé qui bouge d'un pixel retape la touche à chaque image. Même schéma pour le clavier du code de salon (`src/ui/ecrans/salon.cpp`, saisie du code WFS-89).

## Règles de gestion
- **RG-01 Un appui = un caractère** : une touche n'écrit (ou n'efface) qu'**une seule fois** par appui, au **poser du doigt** ; tant que le même doigt (même `id`) reste posé, ses mouvements n'écrivent rien. Un nouveau caractère ne vient qu'après que ce doigt s'est levé (ou d'un autre doigt qui se pose).
- **RG-02 Délai après chaque appui (demande de l'utilisateur)** : après chaque caractère accepté, **150 ms** pendant lesquels aucun autre appui sur le clavier n'est accepté (rebond du doigt, double évènement Android). 150 ms laissent taper vite (≈ 6 touches par seconde).
- **RG-03 Tous les claviers du jeu** : clavier de « Crée ton pilote » (pseudo et plaque) **et** clavier du code de salon du duel (4 cases, effacer) suivent RG-01 et RG-02. Les autres boutons (« C'est parti », « Rejoindre », changement de champ) ne changent pas de comportement.
- **RG-04 Ne rien casser** : la conduite et les commandes tactiles de course (qui ont besoin des mouvements `down = true`) ne changent pas : la correction se fait **dans les écrans de saisie**, pas dans `android_main.cpp` ni dans `Game::onTouch` (noyau partagé interdit hors E0). Retour visuel de la touche (120 ms) gardé.
- **RG-05 Test** : un test CPU (dossier `tests/`) envoie à `toucher()` un appui suivi de 10 mouvements du même doigt puis le lever → **1** caractère ; deux appuis à 50 ms d'écart → 1 caractère ; deux appuis à 200 ms → 2 caractères ; même chose pour « effacer ».
