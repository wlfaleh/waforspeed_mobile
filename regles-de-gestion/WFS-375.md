## Constat (vidéo)
Sur « Choisis ton terrain », le bouton Jour fait défiler **Midi → Dorée → …** (WFS-208 : aube, matin, midi, dorée, réelle ; Nuit : bleue, nuit). L'utilisateur a choisi sans le vouloir « Dorée » : la course part au coucher du soleil, ce qui n'est ni jour ni nuit. Il veut **deux modes simples**.

## Règles de gestion
- RG-01 Deux boutons seulement : **JOUR** et **NUIT**. Un appui choisit le mode ; un 2e appui ne fait plus rien défiler. L'étiquette affichée est « JOUR » ou « NUIT », jamais « Midi », « Dorée », « Aube », « Bleue », « Réelle ».
- RG-02 Jour = moment **Midi** (soleil haut, `atmosphere::Moment::Midi`) ; Nuit = moment **Nuit**. Le choix est gardé d'une partie à l'autre (`sauvegarde().moment`).
- RG-03 Une ancienne sauvegarde avec un autre moment (aube, matin, dorée, réelle → Jour ; bleue → Nuit) se range dans le bon des deux modes au chargement.
- RG-04 **Ordre de l'utilisateur, appliqué tel quel** : seul le choix du joueur est simplifié. Le code des moments (`atmosphere_physique.*`, `eclairage_*`, bancs WFS-208) **reste** (bancs de lumière) : on ne retire rien d'autre.
- RG-05 Parcours complet testé : accueil → choix du terrain (Jour, puis Nuit) → course → retour → choix gardé.
- RG-06 Après la fusion : **🟡 À valider (utilisateur)**.
