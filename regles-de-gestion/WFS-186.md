- les fichiers `.glb` sont déposés dans `assets/world/animaux/` avec leur licence ;
- ou un agent trouve une source accessible (GitHub brut, npm) dont la licence libre est **vérifiée dans le fichier de licence de la source** (CC0 de préférence ; CC-BY accepté avec l'attribution dans `assets/licences/`). Licence non vérifiable = source refusée.
