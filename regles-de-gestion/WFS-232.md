# WFS-232 — [RÉALISME] Deux-roues dans la rue : motos et scooters dans le trafic, garés le long des trottoirs

## Règles de gestion
- RG-01 : 3 à 5 modèles de deux-roues réels (scooter urbain, moto routière, moto sportive, cyclomoteur) trouvés dans les dépôts GitHub publics (CC0 / CC BY,
  `modeles-3d-github.md`), dimensions ±1 %, **avec pilote casqué** (personnages du jeu) ; noms inventés comme les voitures (WFS-191).
- RG-02 : dans le trafic : 10 à 15 % des véhicules en Ville et sur la Corniche, 5 % en Campagne ; ils roulent dans la voie (à droite), se faufilent un peu
  aux feux et dans les bouchons, s'inclinent dans les virages ; collisions et quasi-contacts comme les voitures (le joueur les évite).
- RG-03 : scooters et motos **garés** le long des trottoirs en Ville et devant les bars de plage ; de nuit, phare et feu arrière allumés (WFS-226).
- RG-04 : budget du téléphone tenu (WFS-222) ; captures `trafic-motos` jour et nuit ; parcours 0 écart ; tests CPU (règles de conduite des deux-roues).
## Critères d'acceptation
