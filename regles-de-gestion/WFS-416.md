## Règles de gestion
- **RG-01 Réutiliser** : la cuisson appelle le code existant (`archi_kit`, `archi_geo`, `archi_ouvertures`, `archi_carte`) ; aucun bâtiment, aucune fenêtre réécrits de zéro. - **RG-03 Le jeu lit et affiche** : au chargement, le jeu lit le bloc des bâtiments du paquet et prépare les maillages ; **pendant la course, aucune construction de bâtiment** (`ajouter()` / `construire()` jamais appelés en course quand le paquet est là) : il choisit seulement le morceau et le niveau à afficher. Test automatique : compteur de constructions en course = 0.
- **RG-04 Fenêtres légères** : vrai 3D de WFS-402 **de près seulement** (niveau 0, ≤ 20 m) ; au-delà, la fenêtre est une **image avec relief** sur la façade (texture de fenêtre + carte de normales / parallaxe : cadre, appui, volets, lames simulés par la lumière), cuite elle aussi ; de nuit, « faux intérieur » éclairé derrière la vitre (plus de rectangles blancs plats). - **RG-06 Secours** : sans paquet (pas téléchargé, version refusée, fichier abîmé), le kit construit par le code reprend la main, **comme aujourd'hui** ; aucun écran noir, aucun plantage ; journal « paquet absent : kit de secours ».
