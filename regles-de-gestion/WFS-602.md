- **Branche** : `feature/waforspeed-602`

## Besoin
Le joueur Windows télécharge `WaForSpeed-Setup.exe`, l'installe, lance le jeu depuis le bureau ou le menu Démarrer et joue en conduite libre et en course, au clavier, à la souris ou à la manette.

## Règles de gestion
- **RG-01** : nouveau point d'entrée `src/platform/windows_main.cpp` (Win32 : `WinMain`, fenêtre, surface Vulkan `VK_KHR_win32_surface`, boucle de messages, temps haute résolution). Il réutilise le jeu et le renderer existants **tels quels** ; partir de `src/platform/desktop_main.cpp` (banc PC) et de `manette.*` / `manette_jeu.*` pour la manette : ne rien recréer qui existe.
- **RG-02** : commandes : clavier (flèches / ZQSD et WASD : volant, gaz, frein ; Espace frein à main ; Échap = pause / retour ; Entrée = valider ; C = caméra), souris dans les menus (clic = toucher), manette XInput (mêmes actions que la manette Android).
- **RG-03** : construction par **compilation croisée MinGW-w64 depuis Linux** : bloc `if(WIN32)` de `CMakeLists.txt` et fichier de chaîne `tools/pc/mingw-w64.cmake` ; aucune ligne Android ni iOS changée.
- **RG-04** : installateur **NSIS** (`tools/pc/installateur.nsi`, script `tools/pc/construire_installateur.sh`) : produit `WaForSpeed-Setup.exe`, installe dans `Program Files\WaForSpeed`, crée un **raccourci bureau** et une entrée **menu Démarrer**, inscrit la **désinstallation** (Paramètres → Applications), le désinstalleur retire tout (sauvegarde du joueur gardée).
- **RG-05** : **pas de Steam, pas d'achats sur PC** : le Market n'achète rien sur PC (pas de `achats_android.cpp` porté) ; pas de publicité.
- **RG-06** : sans son, sans réseau et sans téléchargement de paquets dans ce ticket (WFS-603, 604, 605) : le jeu démarre quand même sans planter (cartes déjà dans l'installateur, duel indisponible avec un message clair).
- **RG-07** : **aucun changement du jeu Android** (APK identique en comportement) ; les ordres permanents (menus ⛔, formes nues interdites) valent : ce ticket ne modifie aucun écran ni aucun objet 3D.
- **RG-08** : fichiers autorisés : `src/platform/windows_main.cpp` (nouveau), `src/platform/windows_*.cpp` si besoin, bloc `WIN32` de `CMakeLists.txt`, `tools/pc/**`, `.gitignore` (sorties). Rien d'autre sans annonce au journal (accroche ≤ 10 lignes).

## Critères d'acceptation
1. `WaForSpeed.exe` construit sous Linux par MinGW ouvre une fenêtre Vulkan et affiche le menu.
2. Menu → Course solo et conduite libre jouables au clavier (parcours complet accueil → course → retour au menu).
3. `WaForSpeed-Setup.exe` installe, crée le raccourci bureau et l'entrée menu Démarrer ; la désinstallation fonctionne.
4. Construction Android et tests inchangés et verts.

## Captures demandées
Si un Windows (ou Wine + pilote Vulkan) est disponible : menu, course au clavier, écran de l'installateur. Sinon : journal de construction MinGW + NSIS, liste du contenu de l'installateur, et captures du banc PC (`desktop_main`) prouvant que le jeu n'a pas changé ; limites écrites dans la PR (essai réel sur Windows par l'utilisateur).
