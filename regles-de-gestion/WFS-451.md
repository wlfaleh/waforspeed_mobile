- **RG-02 Commentaire** : le commentaire de `cameraTempsSimule` revient à côté de sa variable dans `src/game/game.h`. Aucun autre changement dans ce fichier.
- **RG-03 Remarques du tableau** (`src/render/banc_telephone.cpp`) :
  - « horodatages non disponibles » (colonnes GPU vides) s'affiche seulement quand **aucun essai** n'a de temps GPU ; si seulement certains essais n'en ont pas, la remarque **nomme ces essais** ;
  - « le téléphone a chauffé » s'affiche seulement quand l'essai de contrôle (tout éteint, à la fin) est **plus lent** que le premier, au-delà du seuil déjà en place ; jamais quand il est plus rapide.
- **RG-04 Test CPU** (`tests/test_banc_telephone.cpp`) : un cas par règle : mode forcé puis rétabli ; mode présent dans le texte du fichier ; un seul essai sans temps GPU ; contrôle plus rapide (pas de remarque de chauffe) ; contrôle plus lent (remarque).
