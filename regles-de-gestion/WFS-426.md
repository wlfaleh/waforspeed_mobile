- RG-02 **Paquets publiés** : `corniche_astc.wfcarte`, `corniche_etc2.wfcarte`, `corniche_rgba8.wfcarte` dans la Release `paquets`, avec leur entrée dans `cartes.json` (taille, SHA-256, adresse directe, version min. de l'APK, format de texture), comme la Ville. - RG-04 **Taille** : **700 Mo maximum sur le disque** (RG-E15-01 du 2026-11-11, plus de minimum) ; taille de chaque paquet dans la PR.
