# WFS-149 — Socle technique : textures compressées KTX2 (ASTC / ETC2) avec mipmaps, tangentes MikkTSpace, shaders découpés par domaine
Épic : E0 (+ `tools/textures/**` nouveau ; `tools/convert_car.mjs` pour les tangentes, accroche annoncée) · Priorité : P2 Haute · Dépend de : WFS-148 validée · Taille : 2 à 3 jours · Palier : 0 — Référence et socle
Charte commune : `regles-de-gestion/DA-realisme.md` (§ 4 fidélité 99 %, RC-01 à RC-11 : validation `qa-lead` avant fusion, pas de fusion par confiance).
Profil d'agent : agent moteur Vulkan.

## Besoin (qui, quoi, pourquoi)
Sans textures compressées, impossible d'ajouter des textures réelles (mémoire et APK). Sans tangentes, les normal maps sont fausses. Avec un seul shader pour tout, quatre épics se marcheraient dessus. Cette US lève les trois limites **sans changer l'image**.

## Règles de gestion
- RG-01 : **Chargeur KTX2** : ASTC 4x4 / 6x6 (Android), repli ETC2 RGBA, repli RGBA8 sur PC ; **toutes les mipmaps** ; sRGB pour la couleur, linéaire pour normales et ORM ; filtrage anisotrope ×8 (×4 en Basse)
- RG-02 : **Outil** `tools/textures/` : PNG / JPG / EXR → KTX2 (mipmaps filtrées en linéaire, normales renormalisées par niveau, regroupement ORM = occlusion, rugosité, métal dans R, G, B), commande unique documentée en 5 lignes ; encodeur libre (licence Apache-2.0) téléchargé ou appelé, licence notée
- RG-03 : **Contrôle de précision de la compression** : l'outil écrit l'écart moyen (PSNR) de chaque texture compressée ; refus sous 38 dB pour la couleur et sous 35 dB pour les normales (sinon bloc plus fin)
- RG-04 : **Tangentes** : `Vertex` gagne une tangente (xyz + signe), MikkTSpace dans `convert_car.mjs`, dans la conversion des personnages et pour la géométrie générée (route, décor) ; formats `.wfm` / `.wfp` versionnés, anciens fichiers toujours lisibles
- RG-05 : **Découpage des shaders** : `scene.frag` et `scene_skin.frag` incluent `route.glsl` (E9), `vehicule.glsl` (E10), `decor.glsl` (E12), `eclairage.glsl` (E13) ; code **déplacé tel quel**, rien de réécrit
- RG-06 : **Image identique** : anciennes captures et `realisme-*` à 0 écart (≤ 1 niveau par canal dû aux tangentes, listé au Journal) ; indice de fidélité inchangé
