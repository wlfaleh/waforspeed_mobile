# WFS-546 — Mode testeur : bouton étoile (+2500 ★ par appui) dans le menu de diagnostic des Réglages

Épic : **E17** (zone E8, `src/ui/ecrans/reglages*`) · Priorité : **P1 Urgent** (demande de l'utilisateur, 2026-11-14 10:57:05 UTC) · Dépend de : — · Développeur : première session `@dev` qui demande un ticket (ou le lead dev en renfort).
Ticket né d'une demande de l'utilisateur pour tester sur son téléphone : après la fusion → **🟡 À valider (utilisateur)**.

## Demande de l'utilisateur (telle qu'écrite)
« Créer le mode testeur : si je rentre dans Réglages et mode diagnostic, mettre un bouton qui permet d'ajouter 2500 étoiles pour chaque clic. »
But : tester les couleurs, finitions, skins et voitures du garage sans devoir gagner les étoiles en course.

## Règles de gestion
- **RG-01 Où** : dans le **menu caché de diagnostic** des Réglages (WFS-419 : 5 touchers sur le titre « Réglages » en moins de 3 s), un bouton **icône étoile** dans la rangée des boutons du haut, à côté de « Banc auto », « Tout rétablir » et « Fermer », même style (`biseau`). Rien ailleurs (menu, garage, Réglages normaux inchangés).
- **RG-02 Effet** : **chaque appui ajoute exactement 2500 ★** au solde du joueur, avec `boutique::crediter(s, 2500, "mode testeur")` (pas de nouveau calcul de solde). Pas de limite au nombre d'appuis. Un appui = 2500 ★ une seule fois (un doigt posé qui bouge ne recrédite pas : même principe que WFS-545).
- **RG-03 Gardé** : le solde est **enregistré dans la sauvegarde** comme après un achat ou une course (fermer et relancer le jeu garde les étoiles) ; le compteur d'étoiles du menu (WFS-537) affiche le nouveau solde.
- **RG-04 Retour visible** : après l'appui, le bouton s'éclaire brièvement ; ligne au journal technique `étoiles : +2500 ★ (mode testeur) : solde N ★` (déjà écrite par `crediter`).
- **RG-05 Bouton = une icône étoile, sans texte (précision de l'utilisateur, 2026-11-14 11:02:49 UTC : « pas besoin de le faire en anglais et français, mettre un bouton avec une icône étoile, c'est tout »)** : le bouton montre seulement une **icône étoile** (★, dessinée comme le ★ du compteur d'étoiles du menu WFS-537), **aucun libellé**, **aucune clé de texte** ajoutée dans `fr.txt` / `en.txt`.
- **RG-06 Test** : un test CPU vérifie : solde 0 → 3 appuis → 7500 ★, sauvegarde relue → 7500 ★.
