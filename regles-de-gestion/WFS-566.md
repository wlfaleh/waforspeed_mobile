# WFS-566 — [URGENT] Market caché dans la version publique tant que WFS-516 n'est pas fini (J-18)
Épic : Publication app (zone : E21 écran Market et ses accès, E8 menus et fin de course ; même réglage de construction que WFS-405) · Priorité : **P1 Urgent** · Dépend de : **décision de l'utilisateur** (question 1 de `tache utilisateur.md` du 2026-11-18 : 1re sortie publique gratuite sans Market ou avec achats) ; **jour de publication** (ordre permanent du 2026-11-10, épic « Publication app ») ; s'appuie sur le réglage de version publique de WFS-405 · Développeur : nouvelle session `@dev` (un sujet par session)
Origine : avis du juriste, `juridique/rapport-2026-11-18.md`, point **J-18** (🔴) : la boutique payante est déjà dans l'APK (`android/app/build.gradle:76`, billing 8.0.0 ; WFS-510, 511, 513 ✅ ; packs 0,99 € à 19,99 €, « sans pub » 2,99 €) alors que `store/cgu.md:11` et `store/confidentialite.md:31` disent « sans achat ». Le juriste recommande une 1re sortie sans Market ; **la décision reste à l'utilisateur**. Si l'utilisateur choisit « avec achats », ce ticket est annulé et WFS-516 (documents, déclarations) passe avant la sortie.

## Besoin
La version publique (AAB Google Play) ne doit montrer ni vendre aucun achat tant que WFS-516 n'est pas fini, pour que le jeu, la fiche, les CGU et la politique de confidentialité disent la même chose (« gratuit, sans achat »).

## Règles de gestion
- RG-01 : **un seul réglage** pour la version publique, le même que WFS-405 (type de construction Gradle ou drapeau), par exemple « marketPublic »: false ; aucune condition copiée dans chaque écran.
- RG-02 : **version publique** : le bouton Market, le compteur d'étoiles qui ouvre le Market, les offres « sans pub » et « Il te manque N ★ » vers le Market, et tout autre accès à l'écran Market **n'apparaissent nulle part** (ni grisés, ni « bientôt »). Le jeu reste entièrement jouable ; le portefeuille d'étoiles gagnées en jeu, le cadeau du jour et le garage restent.
- RG-03 : **version publique** : la bibliothèque de paiement n'est **pas appelée** (aucune connexion à Google Play Billing, aucun produit demandé) ; si c'est simple, elle n'est pas dans l'AAB public (sinon le noter au PO pour un ticket suivant, la permission `BILLING` doit alors être déclarée dans la Console par WFS-516).
- RG-04 : **aucun produit créé dans la Play Console** pour la version publique (rappel pour l'utilisateur et l'agent expert ci, écrit dans `store/checklist.md`).
- RG-05 : **APK d'aperçu** : le Market reste tel quel (tests de l'utilisateur, WFS-515). Rien n'est supprimé du dépôt, aucun code du Market retiré.
- RG-06 : sauvegarde : un achat « sans pub » déjà présent dans une sauvegarde d'aperçu ne plante pas la version publique.
- RG-07 : tests CPU verts, 0 erreur de validation Vulkan, parcours complet accueil → course → fin de course → retour, dans les deux versions. Délai : une journée au plus.

## À réutiliser
Le réglage de version publique de WFS-405 ; l'écran Market de WFS-513, la logique de WFS-510 et la passerelle Billing de WFS-511 (seulement masqués, jamais réécrits).
