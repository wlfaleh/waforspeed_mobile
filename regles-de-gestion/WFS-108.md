# WFS-108 — [URGENT] Commandes tactiles : boutons plus grands, frein et marche arrière revus, option gyroscope
Épic : E3 (`src/game/commandes_tactiles.*`) · Priorité : P1 Urgent · Dépend de : WFS-98 ✅ · Taille : 2 jours · Retour de l'utilisateur (`tache utilisateur.md`) : boutons accélération, frein, turbo et flèches trop petits ; frein et marche arrière à revoir ; ajouter un mode gyroscope avec les flèches ou le glissement

## Besoin
Les commandes sont difficiles à utiliser sur téléphone : trop petites, le frein et la marche arrière ne se comportent pas comme on s'y attend, et il manque une direction au gyroscope.

## Règles de gestion
- RG-01 : **boutons plus grands** : GAZ, FREIN, NITRO et flèches gauche/droite d'au moins **48 dp** (idéal 64 à 80 dp pour GAZ / FREIN), espacés pour ne pas se toucher, dans les marges de sécurité (encoche) ; zone de toucher plus grande que le dessin.
- RG-02 : **frein et marche arrière** : appui sur FREIN = frein ; **maintenu à l'arrêt = marche arrière** sans attendre ni relâcher ; un bouton ou geste clair pour la marche arrière (au choix : maintien du frein, ou bouton « R ») ; passer de l'avant à l'arrière est fluide ; le HUD indique « R » en marche arrière (WFS-27). **Vérifier le comportement actuel sur captures / tests CPU** et corriger ce qui ne va pas, noté au journal.
- RG-03 : **modes de direction** (réglage de WFS-41 / WFS-70) : « flèches », « glissement », et **« gyroscope »** (incliner le téléphone ; capteur de rotation Android ; sensibilité et zone morte réglables ; réétalonnage au départ de course). Le gyroscope peut se combiner avec les flèches ou le glissement, selon le choix du joueur.
- RG-04 : le choix de direction et la taille des boutons (Normal / Grand) sont mémorisés (WFS-24) et réglables dans les réglages.
- RG-05 : le gyroscope accède au capteur par un point d'extension Android annoncé (`android/**`, ≤ 10 lignes d'accroche) ; sur le banc PC, simulé par des valeurs d'essai.
- RG-06 : **gel iOS** : ne rien faire pour iOS.

## À réutiliser du jeu web
`css/style.css` / `index.html` : `steerZone`, `pedal`, `nitroTouch` (tailles, disposition) ; `js/game/update.js` (frein / marche arrière : « maintenu à l'arrêt, il passe la marche arrière »).

## Critères d'acceptation
- [ ] captures du HUD tactile : boutons nettement plus grands (≥ 48 dp), sans chevauchement ni empiètement sur l'encoche
- [ ] test CPU : frein maintenu à l'arrêt → marche arrière ; reprise de l'accélération → avant
- [ ] gyroscope : valeurs d'essai → braquage ; l'utilisateur confirme sur téléphone
