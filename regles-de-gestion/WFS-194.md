# WFS-194 — Voitures sans marque (phase 4/4) : remplacer les 5 modèles sous licence « non commerciale »
Épic : E10 · Priorité : P4 (conditionnelle) · Dépend de : **décision de l'utilisateur de vendre le jeu ou d'y mettre pubs / achats**, WFS-158 fusionné · Origine : constat du PO, 2026-11-06

## Constat
Cinq modèles 3D sont sous licence non commerciale (`src/game/cars.h`) : T-Cross (CC BY-NC-SA 4.0), X5 (CC BY-NC-SA 4.0), A 45 (CC BY-NC 4.0),
Elantra N (CC BY-NC 4.0), Mustang Shelby GT500 (CC BY-NC-SA 4.0). Modifiés ou renommés, ils restent non commerciaux (œuvre dérivée).
Interdits dans un jeu vendu, ou avec publicité ou achats ; utilisables tant que le jeu reste gratuit, sans pub ni achat.

## Règles de gestion
- RG-01 : ticket **⏳ En attente** tant que l'utilisateur n'a pas décidé ; aucun agent ne le démarre seul.
- RG-02 : pour chaque voiture, une des voies, choisie par l'utilisateur : (a) autre modèle de la même voiture sous CC0 / CC-BY, cherché dans les dépôts GitHub publics
  (`.claude/skills/waforspeed-natif/references/modeles-voitures-github.md`, règles de `regles-reseau.md`, comme RG-D de WFS-158) ; (b) accord écrit de l'auteur pour l'usage commercial, obtenu par l'utilisateur (les agents
  n'écrivent à personne) et rangé dans `assets/licences/` ; (c) autre voiture.
- RG-03 : mêmes exigences que RG-D de WFS-158 : dimensions ±1 %, sans facettes, feux, peintures, LOD, budget du téléphone ; puis noms
  (WFS-191), logos (WFS-192) et retouches (WFS-193) appliqués au nouveau modèle.
