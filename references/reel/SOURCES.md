# Référentiel du réel — sources (WFS-148, RG-01)

Chaque valeur des fichiers JSON de ce dossier cite une source de cette liste (champ `source`) et porte une tolérance
(champ `tolerance`, règles de `regles-de-gestion/DA-realisme.md` § 4) et un **statut** :

| Statut | Sens |
|---|---|
| `verifie` | lue dans un jeu de données téléchargé, dont l'empreinte SHA-256 est notée (base Physically Based, ANSUR II, valeurs de contrôle calculées par pvlib) |
| `derive` | calculée à partir d'une valeur sourcée ; la formule est écrite dans le champ `formule` |
| `a_confirmer` | relevée dans une source citée dont la page n'a **pas pu être ouverte** depuis la session (réseau limité : Wikipédia, Légifrance, Cerema, NOAA, sites constructeurs refusés) : valeur lue dans le résumé du moteur de recherche ou dans une copie publiée ; à confirmer sur la page citée |
| `a_sourcer` | aucune valeur fiable trouvée : champ `valeur` à `null`, la mesure est « non mesurable » dans le rapport, avec la raison |
| `conception` | choix de conception (lieux fictifs des cartes), pas une donnée mesurée ; à valider par le PO |

Plage de valeurs (`min` / `max`) : les sources ne concordent pas ou la valeur dépend de la version ; la tolérance s'applique aux bornes.
Contrôle automatique : `test_fidelite` (`tests/fidelite_referentiel.cpp`) refuse une valeur sans source, sans tolérance ou sans statut.
Reproduire les fichiers extraits : `outils/extraire.py` (jeux de données libres) ; relevés manuels : `outils/releves.py`.
