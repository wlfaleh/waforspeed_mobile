## The game

WaForSpeed is a car racing game for phones. It is free, with no account, no ads and no in-game purchases. By tapping "Accept", you accept these terms and the privacy policy that follows. If you decline, the game does not start.

## Map downloads

- The game downloads its **map packs** from the project's GitHub Releases. The address is set in the game's configuration file (configgame.json); the game downloads from no other site.
- The **size** of a pack is shown before the download. **Wi-Fi is recommended**: on mobile data, nothing is downloaded until you tap "Install".
- A downloaded file is checked (checksum) before it is used. It contains only game data: it is never executed.
- **Without Internet**, the game stays playable: the backup map shipped with the game is used.
- As with any web page, **GitHub (the host) receives the phone's IP address** with each download. The game itself sends no personal data.

## Data kept on the phone

- The save file (settings, records, chosen car, version of the accepted terms) and the map packs stay in the **app's private folder**.
- Everything is deleted when you uninstall the game. Map packs will also be able to be deleted one by one from the track selection.

## Driving and safety

- WaForSpeed is a game: never copy its driving on a real road. Follow the traffic laws.
- Do not play while driving, while walking in the street or in any situation that needs your attention.
- Take regular breaks. If you feel unwell, or get headaches or dizziness, stop playing.

## The game as it is

The game is provided as is, with no guarantee that it works on every phone. The licenses of the models, sounds and fonts used are in the game's credits.

## Changes

If these terms change, their version number changes and the game shows them to you again at the next launch.
