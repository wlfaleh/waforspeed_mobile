# Conditions d'utilisation — WaForSpeed

Version 1 — 2026-11-08

*Brouillon : relecture juridique conseillée avant publication sur le Play Store (WFS-308).*

## Le jeu

WaForSpeed est un jeu de course automobile pour téléphone. Il est gratuit, sans compte, sans publicité et sans achat dans le jeu. En appuyant sur « Accepter », tu acceptes ces conditions et la politique de confidentialité qui suit. Si tu refuses, le jeu ne démarre pas.

## Téléchargement des cartes

- Le jeu télécharge ses **paquets de cartes** depuis les Releases GitHub du projet. L'adresse est fixée dans le fichier de configuration du jeu (configgame.json) ; le jeu ne télécharge depuis aucun autre site.
- La **taille** d'un paquet est annoncée avant le téléchargement. Le **Wi-Fi est conseillé** : sur les données mobiles, rien n'est téléchargé sans ton appui sur « Installer ».
- Un fichier téléchargé est vérifié (somme de contrôle) avant d'être utilisé. Il ne contient que des données de jeu : il n'est jamais exécuté.
- **Sans Internet**, le jeu reste jouable : la carte de secours livrée avec le jeu est utilisée.
- Comme pour toute page web, **GitHub (l'hébergeur) reçoit l'adresse IP du téléphone** à chaque téléchargement. Le jeu, lui, n'envoie aucune donnée personnelle.

## Données gardées sur le téléphone

- La sauvegarde (réglages, records, voiture choisie, version des conditions acceptées) et les paquets de cartes restent dans le **dossier privé de l'application**.
- Tout est effacé quand tu désinstalles le jeu. Les paquets de cartes pourront aussi être supprimés un par un depuis le choix du terrain.

## Conduite et sécurité

- WaForSpeed est un jeu : ne reproduis jamais sa conduite sur une vraie route. Respecte le code de la route.
- Ne joue pas en conduisant, en marchant dans la rue ou dans toute situation qui demande ton attention.
- Fais des pauses régulières. Si tu ressens un malaise, des maux de tête ou des vertiges, arrête de jouer.

Le jeu est fourni tel quel, sans garantie de fonctionnement sur tous les téléphones. Les licences des modèles, sons et polices utilisés sont dans les crédits du jeu.
